# 地震台站数据质量检测服务

纯后端 Node.js + TypeScript + Fastify 服务，面向地震台站观测数据接入与质量检测。

## 能力

- 台站档案管理
- 观测摘要批量接入（批次幂等）
- 采样完整性、波形削顶、时间同步检测
- 质量评分与问题标签
- 按台站/分数查询观测记录
- 生成时间窗口质量报告

## 批量接入与幂等

`POST /api/observations/ingest/batch`，请求体：`{ "batchId": "...", "observations": [...] }`（1–1000 条）。

- **逐条校验**：有效记录正常评分入库，无效记录在 `rejected` 中按索引给出原因（参数校验失败 / 台站不存在），互不影响。
- **批次幂等**：`batchId` 为幂等键。网络重试原样重发时返回 `200` + `replay: true` 与首次完全一致的结果（含原观测 ID），观测不会重复入库，质量报告的数量、平均分与问题汇总不受重复提交影响。
- **冲突检测**：同一 `batchId` 提交不同内容返回 `409`，防止批次标识被误复用。
- **台站状态**：仅被接收的观测会刷新台站 `lastSeenAt` 并将状态置为 `online`。

## 启动

```bash
npm install
npm run dev
```

默认端口：`4301`。当前使用内存存储，后续可替换 PostgreSQL/时序数据库，并接入 Kafka、SeedLink 或对象存储。
