# 地震台站数据质量检测服务

纯后端 Node.js + TypeScript + Fastify 服务，面向地震台站观测数据接入与质量检测。

## 能力

- 台站档案管理
- 观测摘要批量接入（批次标识幂等，重复提交不产生重复数据）
- 采样完整性、波形削顶、时间同步检测
- 质量评分与问题标签
- 按台站/分数查询观测记录
- 生成时间窗口质量报告

## 批量接入与幂等

`POST /api/observations/ingest/batch`，请求体：`{ "batchId": "批次标识", "observations": [ ...观测记录 ] }`（单批 1–500 条）。

- **幂等**：以 `batchId` 去重。首次处理返回 `201`；网络重试原样重交返回 `200` 与首次完全一致的结果（相同的观测 id、数量、拒绝明细），并标记 `deduplicated: true`，不产生任何重复写入或台站状态副作用；同一 `batchId` 携带不同内容返回 `409`。
- **部分无效**：逐条校验，有效记录正常评分入库，无效记录按下标返回 `rejects` 原因（含"台站不存在"），响应中 `total / accepted / rejected` 数量明确。
- **一致性**：只有真正接收的观测才会进入观测库，后续质量报告的数量、平均分与问题汇总不受重复提交影响；批次内接收的观测会将台站置为 `online` 并推进 `lastSeenAt`（不会回退）。

## 启动

```bash
npm install
npm run dev
```

默认端口：`4301`。当前使用内存存储，后续可替换 PostgreSQL/时序数据库，并接入 Kafka、SeedLink 或对象存储。
